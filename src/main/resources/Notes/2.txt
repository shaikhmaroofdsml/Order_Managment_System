# Step 1: Understand the Relationship

A category can have many products.

Example:

```text
Electronics
   |
   |------ iPhone
   |------ Samsung S25
   |------ OnePlus 14

Fashion
   |
   |------ Shirt
   |------ Jeans
```

Database:

```sql
Category
--------
id
name

Product
--------
id
name
price
stock
description
category_id
```

Notice the **foreign key**:

```text
Product.category_id  ---> Category.id
```

This is a **Many-to-One** relationship.

---

# Step 2: Create Product Entity

```java
@Entity
@Table(name = "products")
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class Product {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable=false)
    private String name;

    @Column(nullable=false)
    private Double price;

    @Column(nullable=false)
    private Integer stock;

    @Column(length = 1000)
    private String description;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "category_id")
    private Category category;
}
```

---

## Why `@ManyToOne`?

Because

```text
100 Products

↓

belong to

↓

1 Category
```

Spring Data JPA creates

```sql
category_id BIGINT
```

automatically.

# Step 3: Update Category

Add reverse mapping.

```java
@OneToMany(mappedBy = "category",
           cascade = CascadeType.ALL,
           fetch = FetchType.LAZY)
private List<Product> products;
```

Now the relationship becomes

```text
Category
   |
OneToMany
   |
Product

Product
   |
ManyToOne
   |
Category
```

This is exactly the type of association mapping covered in your notes.

# Step 8: Create Product

This is where you learn how relationships work.

```java
@Override
public ProductResponse create(ProductRequest request) {

    Category category = categoryRepository.findById(request.getCategoryId())
            .orElseThrow(() -> new RuntimeException("Category not found"));

    Product product = Product.builder()
            .name(request.getName())
            .price(request.getPrice())
            .stock(request.getStock())
            .description(request.getDescription())
            .category(category)
            .build();

    Product saved = productRepository.save(product);

    return ProductResponse.builder()
            .id(saved.getId())
            .name(saved.getName())
            .price(saved.getPrice())
            .stock(saved.getStock())
            .description(saved.getDescription())
            .categoryName(saved.getCategory().getName())
            .build();
}
```

---

# What's Happening Here?

### Client sends:

```json
{
    "name":"MacBook Pro",
    "price":2500,
    "stock":5,
    "description":"Apple Laptop",
    "categoryId":1
}
```

↓

Find Category

```java
Category category = categoryRepository.findById(1).get();
```

↓

Attach Category

```java
product.setCategory(category);
```

↓

Save

```java
productRepository.save(product);
```

Hibernate inserts

```sql
INSERT INTO products
(name,price,stock,description,category_id)
VALUES
('MacBook Pro',2500,5,'Apple Laptop',1);
```

This is one of the most important Spring Data JPA concepts to understand.

# Step 9: Get All Products

```java
@Override
public List<ProductResponse> getAll() {

    return productRepository.findAll()
            .stream()
            .map(product -> ProductResponse.builder()
                    .id(product.getId())
                    .name(product.getName())
                    .price(product.getPrice())
                    .stock(product.getStock())
                    .description(product.getDescription())
                    .categoryName(product.getCategory().getName())
                    .build())
            .toList();
}
```
