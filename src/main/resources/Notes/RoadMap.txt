# Step 7: Create First Entity - Category

We'll start with **Category** because Product depends on it.

Database table:

```
Category
------------------

id

name

description
```

Entity:

```java
@Entity
@Table(name = "categories")
public class Category {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;

    private String description;
}
```

Here you'll use the entity mapping annotations you've studied (`@Entity`, `@Table`, `@Id`) and MySQL's identity strategy for primary key generation.

# What You'll Learn in Phase 1

In the next phase, we'll implement the complete **Category Module** using Spring Data JPA:

* Create a `CategoryService` interface and implementation
* Build REST APIs (`POST`, `GET`, `PUT`, `DELETE`)
* Use `JpaRepository` methods like `save()`, `findAll()`, `findById()`, and `deleteById()`
* Validate requests using `@Valid`
* Return proper HTTP status codes
* Test APIs with Postman
* Observe the SQL generated by Hibernate in the console

By the end of Phase 1, you'll have built a fully functional CRUD module and understand exactly how Spring Data JPA translates repository calls into database operations.

**Don't skip ahead.** Build one module completely before moving to the next. By the time we reach the Product and Order modules, the more advanced JPA features will make much more sense.
