
Great. Now we are entering the **most important feature of Spring Data JPA**—**Derived Query Methods** (`findByXXX`). This is heavily asked in interviews and widely used in real projects.

Your notes introduce this concept as writing repository methods where **Spring Data JPA generates the SQL automatically based on the method name**.

# Phase 3: Derived Query Methods

## Goal

Implement product search without writing SQL.

Instead of writing SQL like:

```sql
SELECT * FROM products WHERE price > 500;
```

You simply write:

```java
findByPriceGreaterThan(Double price);
```

Spring Data JPA generates the SQL for you.

# Method 1: Find By Name

```java
List<Product> findByName(String name);
```

Generated SQL

```sql
SELECT * FROM products
WHERE name = ?;
```

---

### API

```
GET /api/products/search/name?name=MacBook
```

---

### Service

```java
public List<ProductResponse> findByName(String name);
```

Implementation

```java
@Override
public List<ProductResponse> findByName(String name) {

    return productRepository.findByName(name)
            .stream()
            .map(this::mapToResponse)
            .toList();
}
```

# Method 8: Find By Category

Because Product has

```java
@ManyToOne
private Category category;
```

Spring lets you navigate relationships.

```java
List<Product> findByCategory(Category category);
```

But clients only know the category ID, so your service can first load the `Category` entity and then call this repository method.

---

# Better Approach

Spring can navigate nested properties.

```java
List<Product> findByCategoryName(String name);
```

No SQL.

No JPQL.

No joins.

Spring generates everything.

---

Example

```
GET /products/category?name=Electronics
```

Returns

```
MacBook

iPhone

Samsung TV
```

# Final ProductRepository

```java
public interface ProductRepository extends JpaRepository<Product, Long> {

    List<Product> findByName(String name);

    List<Product> findByNameContaining(String keyword);

    List<Product> findByPriceGreaterThan(Double price);

    List<Product> findByPriceLessThan(Double price);

    List<Product> findByPriceBetween(Double min, Double max);

    List<Product> findByStockLessThan(Integer stock);

    List<Product> findByCategory(Category category);

    List<Product> findByCategoryName(String categoryName);

    List<Product> findByCategoryNameAndPriceLessThan(
            String category,
            Double price);

    List<Product> findByOrderByPriceAsc();

    List<Product> findByOrderByPriceDesc();

    List<Product> findTop5ByOrderByPriceDesc();

    Product findFirstByOrderByPriceAsc();

    long countByCategoryName(String category);

    boolean existsByName(String name);
}
```
