
Excellent. Now we'll learn the feature that separates beginners from intermediate Spring Data JPA developers.

# Phase 4: Custom Queries (`@Query`)

Until now, Spring generated SQL from method names.

Sometimes, that's not enough.

Example:

* Join multiple tables
* Aggregate data
* Reports
* Dashboard queries
* Complex filtering

Then we use **`@Query`**.

This matches the "Custom Queries" section in your notes, including JPQL and native SQL.

---

# Step 1: JPQL vs Native SQL

## JPQL (Recommended)

Uses **Entity name** and **Entity fields**.

```java
@Query("FROM Product")
List<Product> getAllProducts();
```

Notice:

* Product = Entity class
* price = Java field
* category = Java object

Not database names.

---

## Native SQL

Uses

* table names
* column names

```java
@Query(value = "SELECT * FROM products", nativeQuery = true)
List<Product> getProducts();
```

---

# Which One Should We Use?

| JPQL                 | Native SQL             |
| -------------------- | ---------------------- |
| Database independent | Database specific      |
| Uses Entity          | Uses Table             |
| Easier maintenance   | Better for complex SQL |
| Recommended          | Only when needed       |

---

Expensive products

```java

FROM Product
```

```java
:price
```

comes from

```java
@Param("price")
```

# Query 5

Search

```java
@Query("""
FROM Product
WHERE lower(name)
LIKE lower(concat('%',:keyword,'%'))
""")
List<Product> search(
        @Param("keyword")
        String keyword);
```

Searches

```text
Book
```

Returns

```text
MacBook

Notebook

Book Stand
```

# Query 6

Projection

Instead of returning the whole Product.

Return

```text
Product Name

Price
```

Repository

```java
@Query("""
SELECT p.name,p.price
FROM Product p
""")
List<Object[]> getNamesAndPrices();
```

Returns

```text
MacBook      1200

iPhone       900

Keyboard      50
```

---

# Better Way (DTO Projection)

Create

```java
public record ProductSummary(

        String name,

        Double price

){}
```

Repository

```java
@Query("""
SELECT new
com.ecommerce.dto.ProductSummary(
p.name,
p.price)
FROM Product p
""")
List<ProductSummary> summary();
```

This is cleaner than `Object[]`.

## Native Join

```java
@Query(value="""
SELECT p.*
FROM products p
JOIN categories c
ON p.category_id=c.id
WHERE c.name=:name
""",

        @Param("name")
        String name);
```
